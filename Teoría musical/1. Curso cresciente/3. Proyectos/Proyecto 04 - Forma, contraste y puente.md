# Proyecto 04 — Forma, contraste y puente

## Encargo

Componer una pieza de 1–2 minutos con una sección A que termine abierta, una sección contrastante B, una transición intencional y un final cerrado.

Este proyecto ataca directamente el bloqueo documentado en [[Composiciones/2. Composición melódica/1. Desarrollo/0. Desarrollo]].

## Formas permitidas

- `A–A'–puente–B–A–coda`.
- Binaria `A–B` con retorno interno.
- Ternaria `A–B–A'`.
- Verso–precoro–coro, si cada función está clara.

## Restricciones

- Máximo dos motivos principales.
- B conserva al menos dos parámetros de A.
- El puente dura 2–8 compases.
- El primer A no usa simultáneamente tónica melódica, cadencia completa, registro máximo y silencio final.
- El clímax se decide antes de arreglar.
- Máximo cuatro capas.

## Plan de siete sesiones

### Sesión 1 — Referencias

- [ ] Analizar forma de tres piezas.
- [ ] Dibujar curvas de energía.
- [ ] Identificar sus señales de cierre.

### Sesión 2 — Material y mapa

- [ ] Elegir motivo y armonía.
- [ ] Completar mapa formal y curva de energía.
- [ ] Escribir función de cada sección.

### Sesión 3 — A abierto

Crear tres finales:

- [ ] semicadencia;
- [ ] resolución melódica incompleta;
- [ ] elisión hacia transición.

Elegir uno después de escuchar.

### Sesión 4 — B relacionado

Completar matriz:

| Parámetro | A | B | Decisión |
|---|---|---|---|
| Motivo | | | |
| Ritmo | | | |
| Registro | | | |
| Armonía | | | |
| Textura | | | |

### Sesión 5 — Puentes

Crear tres versiones:

- [ ] fragmentación;
- [ ] nota común o bajo dirigido;
- [ ] reducción de densidad o anticipación.

Elegir la versión más inevitable, no la más complicada.

### Sesión 6 — Toma completa

- [ ] Ejecutar o exportar sin detenerse.
- [ ] Marcar dónde cae la atención.
- [ ] Identificar compases sin función.

### Sesión 7 — Revisión y cierre

- [ ] Eliminar o condensar al menos una redundancia si existe.
- [ ] Fortalecer clímax o cierre.
- [ ] Recibir feedback.
- [ ] Exportar 1.0.

## Pruebas

### Retención

- [ ] Dibujar de memoria forma y energía.
- [ ] Cantar el material que conecta A y B.

### Transferencia

- [ ] Crear otro puente para la misma A/B usando una receta distinta.

## Preguntas de cierre

- ¿A promete continuación?
- ¿B contrasta sin perder identidad?
- ¿El puente conecta o retrasa?
- ¿El clímax utiliza recursos reservados?
- ¿La repetición final cambia el significado de A?
- ¿La pieza concluye o simplemente se apaga?
