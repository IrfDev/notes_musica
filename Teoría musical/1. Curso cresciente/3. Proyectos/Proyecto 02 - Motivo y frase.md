# Proyecto 02 — Motivo y frase

## Encargo

Componer una miniatura melódica de 16 compases con forma `A–A'–B–A` o período expandido, partiendo de una idea cantada.

## Restricciones

- Generar primero con voz, sin instrumento durante veinte minutos.
- Utilizar 5–7 alturas en el primer borrador.
- Máximo tres acordes o un pedal durante la generación melódica.
- Una célula principal.
- Un punto culminante reservado.
- B conserva dos propiedades de A y cambia una o dos.
- Duración de 45–75 segundos.

## Habilidad principal

Desarrollar identidad melódica sin acumular motivos.

## Plan de seis sesiones

### Sesión 1 — Voz y selección

- [ ] Grabar diez ideas de 5–15 segundos.
- [ ] No nombrar tonalidad durante la generación.
- [ ] Escuchar al día siguiente.
- [ ] Elegir dos por memorabilidad y potencial.

### Sesión 2 — Transcribir y reducir

- [ ] Encontrar la idea en guitarra o piano.
- [ ] Escribir ritmo y alturas.
- [ ] Señalar notas estructurales.
- [ ] Identificar ritmo, contorno e intervalo característico.

### Sesión 3 — Variar

Crear al menos:

- [ ] repetición;
- [ ] cambio de final;
- [ ] fragmentación;
- [ ] extensión;
- [ ] desplazamiento;
- [ ] ornamentación;
- [ ] cambio de registro.

### Sesión 4 — A, A' y B

| Parámetro | A | A' | B |
|---|---|---|---|
| Ritmo | | | |
| Contorno | | | |
| Registro | | | |
| Final | | | |
| Densidad | | | |

- [ ] Diseñar primero la tabla.
- [ ] Construir 16 compases.

### Sesión 5 — Armonía mínima

- [ ] Añadir bajo o acordes que apoyen dirección.
- [ ] Comprobar que la melodía funciona sola.
- [ ] Evitar resolver un problema de frase con armonía compleja.

### Sesión 6 — Captura y feedback

- [ ] Grabar o exportar.
- [ ] Escuchar después de 24 horas.
- [ ] Pedir a una persona que tararee lo que recuerda.
- [ ] Revisar una dimensión.
- [ ] Cerrar versión 1.0.

## Pruebas

### Retención

- [ ] Cantar toda la melodía 48 horas después.
- [ ] Identificar sus notas estructurales sin partitura.

### Transferencia

- [ ] Tocar el motivo en otra tonalidad.
- [ ] Cambiar de instrumento.
- [ ] Crear una variación con ritmo diferente y misma estructura de grados.

## Preguntas de cierre

- ¿Qué hace reconocible al motivo?
- ¿B pertenece realmente a la misma pieza?
- ¿La nota culminante está preparada?
- ¿Cada frase respira?
- ¿Qué ornamentación podría eliminarse?
- ¿Qué material se utilizará en Proyecto 03?
