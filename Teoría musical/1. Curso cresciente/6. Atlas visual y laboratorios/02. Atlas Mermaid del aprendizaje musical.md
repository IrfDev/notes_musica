# Atlas Mermaid del aprendizaje musical

> [!note] Cómo usarlo
> No memorices los diagramas. Úsalos para localizar una relación, elegir una acción y volver al sonido. Cada mapa termina en una pregunta o producto.

# 1. Del conocimiento a la capacidad

```mermaid
flowchart LR
    A["Leer o recibir explicación"] --> B["Reconocer"]
    B --> C["Recuperar sin mirar"]
    C --> D["Escuchar o cantar"]
    D --> E["Reproducir en ejercicio"]
    E --> F["Elegir en pieza propia"]
    F --> G["Transferir a otro contexto"]
    G --> H["Diagnosticar y revisar"]
    H --> I["Integrar o evitar con criterio"]
```

**Uso:** marca el último nodo que puedes demostrar con audio. Todo lo que está a la derecha sigue siendo brecha, aunque el término resulte familiar.

# 2. Sistema completo de composición

```mermaid
flowchart TD
    REF["Referencia y escucha"] --> INT["Intención"]
    INT --> RES["Restricción"]
    RES --> GEN["Generar alternativas"]
    GEN --> SEL["Seleccionar"]
    SEL --> DEV["Desarrollar"]
    DEV --> FOR["Probar forma completa"]
    FOR --> ARR["Arreglar / interpretar"]
    ARR --> REC["Grabar / exportar"]
    REC --> EVA["Evaluar diferido"]
    EVA --> REV["Revisar"]
    REV --> FIN["Cerrar y archivar"]
    FIN --> TRA["Transferir lección"]
    TRA --> REF

    EVA -. "problema de idea" .-> GEN
    EVA -. "problema estructural" .-> FOR
    EVA -. "problema de capas" .-> ARR
    EVA -. "problema de ejecución" .-> REC
```

**Uso:** cuando te bloquees, señala dónde estás. No abras una etapa nueva si el problema real está dos nodos atrás.

# 3. Estado de una habilidad

```mermaid
stateDiagram-v2
    [*] --> Desconocida
    Desconocida --> Reconocida: leer / observar
    Reconocida --> Recuperable: recordar sin ayuda
    Recuperable --> Audible: cantar / identificar
    Audible --> Controlada: ejercicio estable
    Controlada --> Aplicada: pieza propia
    Aplicada --> Transferible: otro contexto
    Transferible --> Integrada: uso con criterio
    Controlada --> Reconocida: no retención
    Aplicada --> Controlada: no transfiere
    Integrada --> [*]
```

**Uso:** la regresión no es fracaso; muestra qué tipo de práctica faltó.

# 4. Sesión autorregulada

```mermaid
sequenceDiagram
    participant Yo
    participant Meta
    participant Instrumento
    participant Grabación
    participant Bitácora

    Yo->>Meta: Define resultado y criterio
    Yo->>Instrumento: Intenta una toma
    Instrumento-->>Yo: Sonido y sensaciones
    Yo->>Grabación: Conserva evidencia
    Yo->>Meta: Compara intención con resultado
    Yo->>Instrumento: Cambia una estrategia
    Yo->>Grabación: Segunda toma
    Grabación-->>Yo: Diferencia audible
    Yo->>Bitácora: Conserva / cambia / prueba
```

**Producto:** dos tomas comparables y una decisión.

# 5. Pirámide de composición

```mermaid
flowchart BT
    A["Pulso, tiempo y escucha"] --> B["Células, grados y gestos"]
    B --> C["Motivos, bajo y voces"]
    C --> D["Frases, continuidad y contraste"]
    D --> E["Secciones, transición y cierre"]
    E --> F["Textura, arreglo e interpretación"]
    F --> G["Producción, revisión y portafolio"]
```

La pirámide no significa que debas “terminar” un piso para componer. Significa que un problema arriba puede originarse abajo.

# 6. Diagnóstico de una sección que no funciona

```mermaid
flowchart TD
    A["La sección no funciona"] --> B{"¿Se reconoce la idea?"}
    B -->|No| C["Reducir material y aclarar motivo"]
    B -->|Sí| D{"¿Tiene dirección rítmica?"}
    D -->|No| E["Revisar pulso, silencios y densidad"]
    D -->|Sí| F{"¿Bajo y voz superior conducen?"}
    F -->|No| G["Probar pares melodía–bajo"]
    F -->|Sí| H{"¿Cumple función formal?"}
    H -->|No| I["Definir inicio, continuación, transición o cierre"]
    H -->|Sí| J{"¿El arreglo comunica?"}
    J -->|No| K["Reducir capas y redistribuir registro"]
    J -->|Sí| L["Revisar interpretación/producción"]
```

# 7. Capas de escucha

```mermaid
flowchart LR
    A["Escucha 1: experiencia"] --> B["Escucha 2: pulso y forma"]
    B --> C["Escucha 3: bajo"]
    C --> D["Escucha 4: melodía/motivo"]
    D --> E["Escucha 5: armonía/voces"]
    E --> F["Escucha 6: textura/producción"]
    F --> G["Síntesis: principio transferible"]
```

**Regla:** no transcribas todos los acordes antes de saber dónde están el pulso, el bajo y las llegadas.

# 8. Proceso de dictado melódico

```mermaid
flowchart TD
    A["Escuchar completo"] --> B["Encontrar pulso y metro"]
    B --> C["Recordar contorno y frase"]
    C --> D["Escribir ritmo"]
    D --> E["Encontrar centro y nota inicial"]
    E --> F["Reconstruir grados/patrones"]
    F --> G["Comprobar puntos difíciles"]
    G --> H["Cantar desde la notación"]
    H --> I{"¿Coincide con memoria?"}
    I -->|No| C
    I -->|Sí| J["Verificar con instrumento"]
```

# 9. Escucha armónica por capas

```mermaid
flowchart TD
    A["Fragmento"] --> B["Centro probable"]
    B --> C["Bajo literal"]
    C --> D["Voz superior"]
    D --> E["Puntos de reposo/tensión"]
    E --> F["Ritmo armónico"]
    F --> G["Voces internas / calidad"]
    G --> H["Etiqueta posible"]
    H --> I{"¿La etiqueta explica algo audible?"}
    I -->|No| J["Conservar descripción sin forzar nombre"]
    I -->|Sí| K["Comparar lectura alternativa"]
```

# 10. Desarrollo motívico

```mermaid
flowchart LR
    M["Motivo"] --> R["Ritmo"]
    M --> C["Contorno"]
    M --> I["Intervalos"]
    M --> L["Longitud"]
    M --> G["Registro"]
    M --> T["Tonalidad/modo"]
    M --> D["Densidad"]
    M --> A["Articulación"]

    R --> V["Variantes"]
    C --> V
    I --> V
    L --> V
    G --> V
    T --> V
    D --> V
    A --> V
    V --> S["Seleccionar por función"]
```

**Uso:** cambia una rama por vez antes de combinarlas.

# 11. Por qué A puede sonar final

```mermaid
flowchart TD
    A["A suena demasiado final"] --> C1["Cadencia fuerte"]
    A --> C2["Duración simétrica completa"]
    A --> C3["Registro descendente/repose"]
    A --> C4["Reducción de actividad"]
    A --> C5["Tónica en bajo y melodía"]
    A --> C6["Silencio largo / cola"]
    A --> C7["Clímax ya consumado"]

    C1 --> S["Probar una variable"]
    C2 --> S
    C3 --> S
    C4 --> S
    C5 --> S
    C6 --> S
    C7 --> S
```

**Producto:** tres finales alternativos conservando el resto de A.

# 12. Energía formal

```mermaid
flowchart LR
    A["Inicio: 1/5"] --> B["Presentación: 2/5"] --> C["Continuación: 3/5"] --> D["Preparación: 4/5"] --> E["Clímax: 5/5"] --> F["Liberación: 2/5"] --> G["Cierre: 1/5"]
```

No toda pieza sigue este arco. Úsalo como modelo que puede confirmarse, invertirse o rechazarse.

# 13. Forma y variables de energía

```mermaid
flowchart TD
    E["Energía percibida"]
    E --> R["Actividad rítmica"]
    E --> D["Densidad"]
    E --> G["Registro"]
    E --> H["Tensión armónica"]
    E --> T["Timbre"]
    E --> V["Dinámica"]
    E --> S["Espacio / silencio"]
    E --> P["Proximidad de llegada"]
```

# 14. Arreglo antes que mezcla

```mermaid
flowchart TD
    A["Problema audible"] --> B{"¿Existe al apagar plugins?"}
    B -->|Sí| C{"¿Se resuelve quitando/moviendo una capa?"}
    C -->|Sí| D["Problema de arreglo"]
    C -->|No| E{"¿Se resuelve cambiando ejecución/sonido fuente?"}
    E -->|Sí| F["Problema de interpretación/captura"]
    E -->|No| G["Probar procesamiento"]
    B -->|No| H["Problema introducido por mezcla"]
```

# 15. Cadena de producción

```mermaid
flowchart LR
    A["Composición"] --> B["Arreglo"] --> C["Interpretación/programación"] --> D["Grabación/edición"] --> E["Balance"] --> F["Procesamiento"] --> G["Automatización"] --> H["Referencia"] --> I["Exportación"]
```

Un error temprano puede amplificarse en cada etapa. Vuelve al primer nodo donde aparece.

# 16. Feedback sin obediencia automática

```mermaid
flowchart TD
    A["Comentario"] --> B{"¿Describe percepción o prescribe solución?"}
    B -->|Percepción| C["Comparar con intención"]
    B -->|Solución| D["Buscar problema subyacente"]
    C --> E{"¿Se repite entre oyentes?"}
    D --> E
    E -->|Sí| F["Prioridad de experimento"]
    E -->|No| G{"¿Afecta objetivo central?"}
    G -->|Sí| H["Probar versión A/B"]
    G -->|No| I["Registrar como preferencia"]
    F --> H
```

# 17. Revisión macro–meso–micro

```mermaid
flowchart TD
    M1["Macro: secciones, duración, clímax, cierre"] --> Q1{"¿La trayectoria funciona?"}
    Q1 -->|No| M1
    Q1 -->|Sí| M2["Meso: frase, capas, registro, ritmo armónico"]
    M2 --> Q2{"¿Cada sección comunica?"}
    Q2 -->|No| M2
    Q2 -->|Sí| M3["Micro: notas, articulación, edición, notación"]
    M3 --> F["Exportar versión"]
```

# 18. Ciclo trimestral

```mermaid
flowchart LR
    A["Semanas 1–4: habilidad y estudio"] --> B["5–8: aplicación y pieza"] --> C["9–11: transferencia/revisión"] --> D["12: evaluación"]
    D --> E{"¿Puerta superada?"}
    E -->|Sí| F["Aumentar una dificultad"]
    E -->|Parcial| G["Repetir tipo con alcance menor"]
    E -->|No| H["Diagnosticar subhabilidad"]
    F --> A
    G --> A
    H --> A
```

# 19. Carga mínima viable

```mermaid
flowchart TD
    T{"Tiempo semanal"}
    T -->|"3 h"| A["Miniatura + oído + toma"]
    T -->|"5 h"| B["Pieza breve + análisis + revisión"]
    T -->|"8 h"| C["Más variantes + feedback + mejor producción"]
    A --> D["Conservar ciclo completo"]
    B --> D
    C --> D
```

El tiempo modifica alcance, no la obligación de terminar.

```mermaid
quadrantChart

```

Los puntos son ejemplos basados en el diagnóstico provisional. Muévelos según tus obras, no según autopercepción solamente.

# 21. Qué medir

```mermaid
flowchart LR
    A["Exposición"] --> A1["minutos / sesiones"]
    B["Desempeño"] --> B1["toma inmediata"]
    C["Aprendizaje"] --> C1["retención diferida"]
    D["Transferencia"] --> D1["otro material/contexto"]
    E["Producción"] --> E1["piezas terminadas"]
    F["Sostenibilidad"] --> F1["dolor, fatiga, motivación"]
```

No confundas exposición con aprendizaje ni toma inmediata con retención.

# 22. Próxima acción universal

```mermaid
flowchart TD
    A["Escucha el resultado"] --> B["Describe un problema audible"] --> C["Elige una variable"] --> D["Haz un cambio mínimo"] --> E["Graba A/B"] --> F["Decide"]
```

Si no puedes formular la acción en menos de 20 minutos, el problema aún es demasiado amplio.
