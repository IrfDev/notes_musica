# Evaluaciones trimestrales y puertas de dominio

> [!note] Principio
> Una evaluación no decide si “eres músico”. Decide qué tipo de problema conviene practicar a continuación. El desempeño se considera estable cuando aparece en dos materiales distintos y no solo en un ejercicio ensayado.

## Preparación

Crea una carpeta con fecha y conserva:

- audio original sin editar;
- partitura, MIDI o lead sheet si existe;
- tempo y condiciones de la prueba;
- número de intentos;
- autoevaluación antes y después de escuchar;
- puntuación y siguiente acción.

No estudies específicamente el material de prueba durante las 24 horas anteriores. Sí puedes calentar de manera normal.

## Escala por criterio

| Puntos | Descripción |
|---:|---|
| 0 | no se intenta o no se reconoce la tarea |
| 1 | resultado parcial con ayuda constante |
| 2 | resultado reconocible pero inestable |
| 3 | resultado funcional y mayormente autónomo |
| 4 | resultado controlado, expresivo y diagnosticable |

Regla general de salida: promedio mínimo 3 en el producto principal y ningún criterio esencial debajo de 2. Una puntuación alta en armonía no compensa pulso inexistente; una mezcla pulida no compensa forma incompleta.

# Evaluación trimestral 1 — Semana 12

## Entregables

- Tres miniaturas: rítmica, monofónica y con ostinato/pedal.
- Seis transcripciones breves.
- Tres análisis de referencia.
- Primera y última grabación de pulso/subdivisión.

## Prueba A — Ritmo

1. Mantén pulso 60 segundos a tempo elegido.
2. Cambia entre negras, corcheas, tresillos y semicorcheas sin detener el pulso.
3. Lee ocho compases nuevos apropiados al nivel.
4. Improvisa ocho compases usando dos células y silencios.

| Criterio | 0–4 |
|---|---:|
| Pulso estable | |
| Subdivisión interior | |
| Precisión de figuras/silencios | |
| Recuperación después de error | |
| Fraseo y dirección | |

## Prueba B — Oído/melodía

1. Canta tónica tras una cadencia o fragmento.
2. Canta dos patrones de grados en tres tonalidades.
3. Retén y reproduce una frase de dos compases.
4. Transcribe ritmo, contorno y alturas por etapas.
5. Canta el motivo de una miniatura propia sin consultar.

## Prueba C — Composición

Evalúa una miniatura:

- identidad rítmica;
- economía de material;
- transformación;
- trayectoria;
- cierre;
- calidad de toma suficiente.

## Puerta

- promedio ≥3 en ritmo y composición;
- promedio ≥2.5 en oído;
- tres productos cerrados;
- al menos una revisión después de descanso.

## Si no se supera

- Reduce la miniatura a 30–45 segundos.
- Limita alturas o capas.
- Mantén 10–15 minutos diarios de oído.
- Repite el ciclo con material nuevo durante cuatro semanas.
- Avanza en armonía solo como acompañamiento del proyecto, no como tema dominante.

# Evaluación trimestral 2 — Semana 24

## Entregables

- Una melodía con tres armonizaciones.
- Un estudio de voces y su transferencia libre.
- Una comparación diatónica/cromática.
- Seis transcripciones adicionales; al menos tres incluyen bajo.

## Prueba A — Bajo y función

Para un fragmento nuevo:

1. encuentra y canta el centro;
2. transcribe el bajo aproximado;
3. señala puntos de reposo y continuidad;
4. identifica función o relación con cautela;
5. propone una alternativa de bajo.

## Prueba B — Armonización

Con una melodía nueva de ocho compases, crea en 60–90 minutos:

- versión estable;
- versión con mayor tensión/continuidad;
- versión de color/ambigüedad.

Conserva tempo e instrumentación. Puntúa:

| Criterio | 0–4 |
|---|---:|
| La melodía conserva identidad | |
| Los bajos son líneas, no raíces mecánicas | |
| Las versiones producen efectos distintos | |
| Conducción clara | |
| Cierres acordes con intención | |
| Explicación basada en sonido | |

## Prueba C — Contrapunto libre

- Escribe ocho compases a dos voces sin cantus dado.
- Cada voz debe poder cantarse.
- Incluye al menos un punto de imitación o respuesta.
- Revisa disonancias y paralelismos según el estilo elegido.
- Convierte el resultado en textura de pieza.

## Puerta

- promedio ≥3 en armonización;
- bajo y melodía se pueden cantar por separado;
- el recurso cromático se reconoce y no es necesario para sostener la pieza;
- tres productos cerrados en el trimestre.

## Si no se supera

Identifica el subproblema:

- Si falla el oído: reducir a melodía–bajo.
- Si falla conducción: dos voces antes de cuatro.
- Si las versiones no difieren: modificar bajo/ritmo armónico antes de añadir acordes.
- Si nada termina: reducir duración y fijar fecha de exportación.

# Evaluación trimestral 3 — Semana 36

## Entregables

- Tres finales de A y transiciones comparadas.
- Una idea en tres formas.
- Obra de 2–3 minutos con dos versiones.
- Seis análisis centrados en forma/cierre.

## Prueba A — Mapa de forma a primera escucha

Selecciona una referencia no analizada. Después de dos escuchas:

- marca secciones y tiempos;
- describe funciones: iniciar, continuar, preparar, llegar, cerrar;
- dibuja energía del 1 al 5;
- anota evidencia de ritmo, registro, densidad, armonía y timbre;
- predice qué ocurrirá antes de una tercera escucha.

## Prueba B — Desarrollo limitado

- Recibe o crea un motivo de dos compases.
- Produce cinco transformaciones en 30 minutos.
- Escribe 45–60 segundos sin otro material principal.
- Marca el origen de cada evento.

## Prueba C — Obra larga

| Criterio | Pregunta | 0–4 |
|---|---|---:|
| Identidad | ¿Se reconoce una familia material? | |
| Continuidad | ¿Cada sección genera la siguiente? | |
| Contraste | ¿B cumple otra función sin parecer otra pieza? | |
| Proporción | ¿Las duraciones sostienen la atención? | |
| Clímax | ¿La máxima intensidad fue preparada? | |
| Cierre | ¿El final corresponde a la escala de la obra? | |
| Revisión | ¿V2 resuelve un problema estructural? | |

## Feedback externo

Pregunta a dos oyentes:

1. ¿En qué momento sentiste una llegada importante?
2. ¿Dónde bajó tu atención?
3. ¿Qué material recuerdas después de cinco minutos?
4. ¿Qué sección parece más o menos conectada?
5. ¿Qué cambio describirías, sin prescribir una solución?

No expliques primero la intención. Compara percepción con intención después.

## Puerta

- obra terminada de 2–3 minutos;
- promedio ≥3 y ningún criterio estructural debajo de 2;
- dos oyentes reconocen al menos una llegada similar;
- existe una revisión macro documentada.

# Evaluación trimestral 4 — Semana 48

## Entregables

- Tres arreglos de una pieza.
- Reconstrucción transformada de referencia.
- Producción terminada.
- Pruebas en tres sistemas de escucha.

## Prueba A — Diagnóstico de capas

Para una sesión propia:

- nombra función de cada capa;
- silencia cada una y describe qué se pierde;
- elimina o combina una redundante;
- identifica conflictos de registro, tiempo y profundidad;
- crea un balance estático nuevo desde cero.

## Prueba B — Arreglo

| Criterio | 0–4 |
|---|---:|
| Funciones claras | |
| Distribución de registro | |
| Trayectoria de densidad | |
| Contraste tímbrico | |
| Melodía/bajo/pulso legibles | |
| El arreglo sostiene la forma | |

## Prueba C — Mezcla

Evalúa a volumen bajo y comparable con referencia:

- balance;
- foco;
- graves;
- profundidad;
- dinámica;
- traducción entre sistemas;
- artefactos o fatiga.

No puntúes “sonido profesional” como una sola impresión. Describe el problema y su localización temporal.

## Puerta

- los tres arreglos son funcionales y distintos;
- la mezcla se reproduce fuera del proyecto;
- el elemento principal sobrevive a bocina pequeña/bajo volumen;
- ningún proceso esencial existe sin diagnóstico;
- la forma funciona antes y después de la mezcla.

# Evaluación trimestral 5 — Semana 60

## Entregables

- Corpus personal de al menos 20 referencias.
- Doce análisis profundos acumulados del estilo elegido.
- Seis transcripciones por capas.
- Tres piezas: imitación estructural, cruce de influencias y anti-hábito.

## Prueba A — Perfil estilístico

Describe tu música mediante:

- tres tendencias rítmicas;
- tres melódicas;
- tres armónicas;
- tres formales;
- tres texturales/tímbricas;
- dos hábitos que empobrecen variedad;
- dos recursos todavía inestables.

Cada afirmación debe enlazar dos obras propias y dos referencias.

## Prueba B — Transferencia

Elige una referencia al azar del corpus:

1. extrae un principio en 20 minutos;
2. crea tres bocetos sin copiar melodía/progresión;
3. desarrolla uno durante 60 minutos;
4. explica qué se conservó en nivel abstracto.

## Puerta

- otra persona no identifica una copia superficial;
- el principio transferido sí se puede señalar;
- las tres piezas varían pero parecen decisiones del mismo compositor;
- puedes prohibir un hábito y conservar intención expresiva.

# Evaluación trimestral 6 — Semana 72

## Entregables

- Tres obras candidatas de portafolio.
- Versiones antes/después.
- Feedback de al menos dos oyentes por obra; intérprete si corresponde.
- Audio final y documentación.

## Matriz de selección

Puntúa de 0–4:

| Criterio | Obra A | Obra B | Obra C | Obra D | Obra E |
|---|---:|---:|---:|---:|---:|
| Identidad | | | | | |
| Forma | | | | | |
| Potencial expresivo | | | | | |
| Calidad técnica | | | | | |
| Viabilidad de terminar | | | | | |
| Representa dirección futura | | | | | |

Selecciona tres después de una semana de distancia. No elijas únicamente las más nuevas ni aquellas con mayor inversión de horas.

## Revisión en tres escalas

### Macro

- orden y duración de secciones;
- función de transiciones;
- clímax y cierre;
- material que sobra o falta;
- tempo global.

### Meso

- fraseo;
- ritmo armónico;
- distribución de capas;
- registro;
- crecimiento y relajación.

### Micro

- notas;
- articulaciones;
- balance puntual;
- edición;
- notación y limpieza.

Nunca comiences por micro si macro todavía cambia.

## Puerta del portafolio

Cada obra debe cumplir:

- [ ] identidad audible en los primeros 30–60 segundos;
- [ ] trayectoria completa;
- [ ] revisión macro y micro;
- [ ] audio final reproducible;
- [ ] partitura/lead sheet/documentación suficiente si aplica;
- [ ] feedback externo procesado;
- [ ] nota de intención/proceso;
- [ ] archivos y versiones ordenados.

Además, el conjunto debe mostrar:

- variedad de tempo, métrica, textura o función;
- una afinidad estilística o de criterio;
- al menos una pieza que desafíe un hábito;
- una dirección clara para los meses 19–24.

# Rúbrica de composición integrada

Usa esta versión para comparar obras a lo largo del tiempo.

| Dominio | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| Intención | ausente | declarada, no audible | parcialmente audible | clara | clara y matizada |
| Material | inconexo | demasiado/derivativo | identidad parcial | económico y reconocible | fértil y flexible |
| Ritmo | sin pulso/dirección | mecánico/inestable | funcional | característico | estructura la obra |
| Melodía | arbitraria | poco cantable | contorno funcional | frasea y recuerda | transforma y comunica |
| Armonía/bajo | aleatoria | etiqueta sin dirección | sostiene | dirige voces/forma | color y función integrados |
| Forma | incompleta | secciones pegadas | trayectoria básica | proporción y transición | inevitabilidad con sorpresa |
| Textura | conflicto | redundancia | legible | energía controlada | timbre/registro estructuran |
| Cierre | accidental | demasiado temprano/tardío | suficiente | preparado | resuelve la escala global |
| Ejecución/producción | impide juzgar | distrae mucho | permite juzgar | comunica | profundiza la obra |
| Revisión | inexistente | cosmética | corrige errores | corrige estructura | revela una versión superior |

No persigas 4 en todos los dominios. Para estudios, define dos criterios principales y exige funcionalidad básica en los demás.

# Cómo procesar feedback

Clasifica cada comentario:

| Tipo | Ejemplo | Respuesta |
|---|---|---|
| Observación | “aquí sentí que terminó” | comparar con intención |
| Problema repetido | tres oyentes pierden foco igual | investigar prioritariamente |
| Preferencia | “prefiero guitarras” | no requiere obediencia |
| Prescripción | “pon un acorde X” | buscar el problema detrás de la solución |
| Confusión técnica | intérprete no entiende notación | corregir documentación |
| Contradicción | oyentes quieren cambios opuestos | decidir por propósito de la obra |

Antes de editar, escribe:

1. ¿Qué percepción se repite?
2. ¿Coincide con mi intención?
3. ¿El origen es composición, interpretación, arreglo o mezcla?
4. ¿Cuál es el cambio mínimo que prueba la hipótesis?
5. ¿Qué versión A/B permitiría comparar?

# Señales de avance genuino

- Detectas el error antes y puedes nombrar su causa probable.
- Necesitas menos intentos para una toma completa.
- Una técnica aparece en una pieza sin que el ejercicio lo exija.
- Puedes transferirla a otra tonalidad, métrica o timbre.
- Tus revisiones retiran material además de añadirlo.
- El feedback se vuelve más específico.
- Terminas con mayor regularidad y menos drama.
- Escuchas diferencias que antes solo conocías en teoría.

# Señales de falsa sensación de avance

- Más carpetas y menos audio.
- Respuestas correctas inmediatamente después de leer, pero no a 48 horas.
- Acordes más complejos sin mejor dirección.
- Mezclas más procesadas sin mejor arreglo.
- Piezas cada vez más largas pero incompletas.
- Repetición del mismo ejercicio memorizado como única prueba.
- Evitar compartir porque “falta aprender otra cosa”.
