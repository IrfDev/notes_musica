## Calibración inicial

Realizar sin estudiar antes. Guardar audio o foto cuando aplique.

### Prueba A — Ritmo

- [ ] Mantener pulso por 60 segundos con click solo al inicio de cada compás.
- [ ] Leer y palmear ocho compases con corcheas, semicorcheas, silencios y ligaduras.
- [ ] Escribir de oído un ritmo de dos compases.
- [ ] Crear cuatro variaciones reconocibles de una célula.

Resultado:

Decisión: `empezar / repasar / superar`

### Prueba B — Oído

- [ ] Cantar la escala mayor por grados.
- [ ] Cantar 1–3–5–3–1 y 1–2–4–3–1 desde tres tónicas.
- [ ] Encontrar en el instrumento una melodía cantada sin ensayo aleatorio excesivo.
- [ ] Transcribir dos compases de una referencia sencilla.

Resultado:

Decisión: `empezar / repasar / superar`

### Prueba C — Melodía

- [ ] Crear un motivo de uno o dos compases.
- [ ] Producir variación, contraste y cierre.
- [ ] Construir ocho compases sin introducir un segundo motivo completo.
- [ ] Cantar la melodía al día siguiente.

Resultado:

Decisión: `empezar / repasar / superar`

### Prueba D — Armonía

- [ ] Construir triadas y séptimas diatónicas en una tonalidad mayor y una menor.
- [ ] Tocar tres inversiones de una triada.
- [ ] Armonizar una melodía sencilla de dos formas.
- [ ] Cantar o identificar el bajo y los tonos guía.

Resultado:

Decisión: `empezar / repasar / superar`

### Prueba E — Forma

- [ ] Dibujar el mapa temporal de una canción sin consultar análisis ajeno.
- [ ] Explicar qué cambia entre A y B.
- [ ] Crear un final abierto y otro cerrado para la misma sección.
- [ ] Terminar una pieza de 60–90 segundos.

Resultado:

Decisión: `empezar / repasar / superar`

### Prueba F — Producción y revisión

- [ ] Grabar una toma completa.
- [ ] Escucharla al día siguiente y encontrar tres observaciones específicas.
- [ ] Realizar una revisión estructural.
- [ ] Exportar una versión final con nombre y fecha.

Resultado:

Decisión: `empezar / repasar / superar`
