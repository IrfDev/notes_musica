# Proyecto 05 — Tres arreglos de una pieza

## Encargo

Tomar el Proyecto 04 y producir tres arreglos que conserven composición y forma, pero cambien identidad mediante textura, registro, articulación y timbre.

## Versiones

### A — Íntima

- 1–2 instrumentos.
- Registro contenido.
- Espacio y respiración.
- Dinámica detallada.

### B — Expansiva

- 3–4 capas.
- Curva de densidad pronunciada.
- Registro amplio.
- Clímax claramente preparado.

### C — Rítmica o inesperada

- Groove más evidente.
- Articulaciones distintas.
- Menos dependencia de arpegio continuo.
- Puede cambiar tempo o métrica si la identidad sobrevive.

## Restricciones

- No reescribir completamente melodía y armonía.
- Máximo cuatro capas simultáneas.
- Cada capa tiene una función.
- Exportaciones comparables en volumen aproximado.
- No usar masterización para decidir composición.

## Plan de seis sesiones

### Sesión 1 — Reducción funcional

- [ ] Reducir la pieza a bajo, soporte y protagonista.
- [ ] Etiquetar función de todas las capas actuales.
- [ ] Eliminar duplicaciones sin propósito.

### Sesión 2 — Versión íntima

- [ ] Diseñar registro.
- [ ] Elegir silencios.
- [ ] Trabajar articulación e interpretación.

### Sesión 3 — Versión expansiva

- [ ] Dibujar densidad por sección.
- [ ] Reservar capa o registro para clímax.
- [ ] Evitar que todo entre en A.

### Sesión 4 — Versión inesperada

- [ ] Cambiar groove, articulación o métrica.
- [ ] Conservar motivo y trayectoria.

### Sesión 6 — Elegir y cerrar

- [ ] Escucha diferida.
- [ ] Feedback ciego.
- [ ] Elegir versión final.
- [ ] Realizar revisión de arreglo.
- [ ] Exportar las tres.

## Pruebas

- [ ] La obra sigue siendo reconocible en las tres versiones.
- [ ] Cada capa tiene función.
- [ ] La versión expansiva no depende solamente de más volumen.
- [ ] La versión íntima no se siente incompleta.
- [ ] La versión rítmica evita el hábito dominante del proyecto original.

## Preguntas de cierre

- ¿Qué pertenece a la composición y qué al arreglo?
- ¿Qué versión revela mejor el motivo?
- ¿Qué capa parecía necesaria y no lo era?
- ¿Dónde el registro cambió más que la armonía?
- ¿Cuál versión representa mejor la intención final?
