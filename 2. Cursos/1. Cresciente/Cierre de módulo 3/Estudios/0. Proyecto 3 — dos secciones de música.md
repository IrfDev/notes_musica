# Proyecto 3 — Dos secciones de música

> [!abstract] Qué es
> El primer proyecto del curso con **checklist explícita**. Dos secciones que funcionen como un todo. **Dos entregas.**

## Los cinco límites, y son claros

| | Requisito |
|---|---|
| **1** | Las dos secciones deben tener una primera frase con **distinto tipo de inicio**. Si una empieza tética, la otra debe empezar anacrúsica o acéfala. |
| **2** | Las dos secciones deben tener **estructura interna distinta**. Si una es AABA, la otra puede ser una oración compuesta; o un ABAC y un 3+1. |
| **3** | **Una de las dos debe incorporar dominantes secundarios.** Pueden ser ambas. |
| **4** | **Como mínimo una resolución deceptiva**, sea del dominante principal o de uno secundario. |
| **5** | Para **conectar** ambas secciones: paso directo, un silencio, o un elemento articulador (una escala, un corte). |

Instrumentación libre. Se puede trabajar con audio, con partitura, o con ambos.

## Procedimiento

1. **Imaginar la música antes de escribirla.** ¿Qué carácter buscas? ¿Qué tempo? ¿Hay una idea inicial que sirva de gatillante, o una imagen? ¿Qué instrumentos participan? La consigna sugiere **dejar pasar uno o dos días** incubando antes de sentarse a componer.
2. Empezar por cualquiera de las dos secciones. Buena idea: arrancar por la **cabeza temática** de cada una — la idea inicial, la primera frase.
3. Con eso resuelto, **probar distintas estructuras internas** para cada sección: una oración, un periodo, un AABA, hasta que se defina cuál queda mejor.
4. Resolver **primero armonía y melodía** de cada sección, con algunos apuntes de la rítmica. A esta altura ya tienes método propio, y cada música pide un proceso ligeramente distinto: notas de voz, tocar en el instrumento, escribir a mano, bitácora.
5. Ir **verificando los cinco límites** mientras compones, no al final.
6. Con el esqueleto armado, **arreglar para el ensamble** elegido y sumar el elemento de transición que haga falta.

Es el proyecto que mejor cierra su módulo: **cada requisito viene de una lección distinta.**

## Qué alimenta

Al tener **dos secciones**, es el mejor candidato de todo el curso para la **Actividad 5B** — que pide justamente una sección con potencial para continuar en otra tonalidad.

## Herramienta

MuseScore para componer las dos secciones: armonía, melodía, estructura interna y tipos de frase necesitan pentagrama.

**Strudel** para el arreglo final si el ensamble pide groove o capas. Y tiene una ventaja concreta para este proyecto: las secciones se encadenan con `arrange([n, seccionA], [n, seccionB])`, donde `n` son los ciclos que dura cada una. **El requisito 5 —cómo conectar ambas secciones— se convierte así en una decisión explícita y editable**, en vez de en un corte que quedó como quedó.

## Criterio de aprobación

Señala en la partitura, compás a compás, **dónde se cumple cada uno de los cinco requisitos**. Si alguno no se puede señalar, no está.

Y el control de oído: la transición entre secciones tiene que sentirse **decidida**, no accidental.
